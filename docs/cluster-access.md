# Cluster Access

The homelab Kubernetes cluster runs on **Talos Linux** with three
control-plane nodes (`talos-cp{1,2,3}`) reachable on the VRRP virtual IP
`192.168.10.245:6443`.

The cluster is managed by **Omni** (`https://omni.f4mily.net`, LAN-only, runs
on srv1). All access goes through Omni: the Kubernetes and Talos APIs are
proxied and authenticated by Omni (OIDC via Authentik). The CAs were rotated
on 2026-10-15 — kubeconfig/talosconfig files generated by OpenTofu in
`homelab-infrastructure/talos/` are **invalid** since then.

## 1. Quick-start

```bash
# omnictl is unfree in nixpkgs
NIXPKGS_ALLOW_UNFREE=1 nix shell --impure nixpkgs#omnictl

# Omni client config: download once from the Omni UI (Settings -> omniconfig)
# to ~/.talos/omni/config, then:
omnictl kubeconfig -c homelab-kube        # merges an OIDC context into ~/.kube/config
omnictl talosconfig -c homelab-kube       # merges a context into ~/.talos/config

kubectl get nodes                         # first call opens the browser (Authentik)
talosctl -n talos-cp1 version
```

## 2. Non-interactive access (scripts, agents)

Use an Omni service account instead of a browser login. Keep the key out of
the repo; prefer short TTLs for ad-hoc tokens:

```bash
export OMNI_ENDPOINT=https://omni.f4mily.net OMNI_SERVICE_ACCOUNT_KEY=...
omnictl kubeconfig -c homelab-kube --service-account --user <who> --ttl 24h --merge=false ./kubeconfig
omnictl talosconfig -c homelab-kube --merge=false ./talosconfig   # needs the same env at use time
```

Break-glass (Omni down): `omnictl kubeconfig --break-glass` /
`omnictl talosconfig --break-glass` — only if enabled for the account; fetch
them **before** you need them and store them offline.

## 4. SOPS / age (decrypting secrets locally)

Encrypted secrets in this repo (anything matching `*.secret.yaml`) are
encrypted with the cluster's age public key (see `.sops.yaml`).

To decrypt locally you need the **private** age key. It lives in the
cluster as `Secret/flux-system/sops-age` and the offline copy is on
the operator workstation only.

```bash
# Either rely on the `age` shell:
nix develop .#age

# … or set the key file directly
export SOPS_AGE_KEY_FILE=~/.config/sops/age/keys.txt
sops -d infrastructure/base/sources/hetzner.secret.yaml
```

For day-to-day secret operations there are `just` helpers in this repo
(`just sops-edit`, `just sops-create`, `just barman-s3-credentials`, …).

Netbird-Mesh-Zugriff auf den Cluster: [netbird-cluster-access.md](netbird-cluster-access.md).  
Services von außen ohne Router-Ports: [netbird-reverse-proxy.md](netbird-reverse-proxy.md).

## 5. Talos administration

```bash
talosctl -n talos-cp1,talos-cp2,talos-cp3 health
talosctl -n talos-cp1 get machineconfig
```

Node config, Talos and Kubernetes versions are declared in
`infrastructure/base/omni-sync/cluster-template.yaml` and pushed to Omni by
the `omni-sync` Deployment. Do not use `talosctl apply-config/patch/upgrade`
or OpenTofu for machine config — Omni (and the sync) would revert or fight it.

## 6. Day-to-day flux commands

```bash
# State of all Flux objects
flux get all -A

# Reconcile after a Git push (no need to wait for the next 1h interval)
flux reconcile source git flux-system
flux reconcile kustomization apps --with-source

# Tail Flux controller logs
kubectl -n flux-system logs -lapp=source-controller       -f
kubectl -n flux-system logs -lapp=kustomize-controller    -f
kubectl -n flux-system logs -lapp=helm-controller         -f
```

## 7. Troubleshooting

| Symptom                                              | Where to look                                |
|------------------------------------------------------|----------------------------------------------|
| Flux `Kustomization` stuck in `Reconciling`          | `flux events`, then `kubectl describe …`     |
| HelmRelease keeps reinstalling                       | `flux events --for HelmRelease/<name>`       |
| Pod `ImagePullBackOff`                               | `kubectl describe pod` — registry / TLS      |
| PVC `Forbidden: spec is immutable`                   | Stale Longhorn PVC, see `docs/applications.md` |
| Cert-manager `Order` failing                         | `kubectl describe order -A` + Hetzner DNS    |
